# 21-Days-SQL-Challenge_Indian-Data-Club

This repository offers a set of synthetic datasets that replicate the operations of a medium-sized hospital. The data covers essential areas such as staffing, patient admissions, and bed allocation across different services, providing an ideal resource for SQL practice and real-world analytical case studies.

### About the Dataset

The dataset was developed for the 21 Days SQL Challenge by the Indian Data Club, designed to help learners strengthen analytical and business problem-solving skills using SQL. You can explore topics such as:

- Hospital resource allocation
- Staff scheduling and assignments
- Patient demand and service trends
- Service performance and satisfaction metrics

### Included Files

| File Name          | Description                                                   |
|--------------------|---------------------------------------------------------------|
| staff.csv          | Full list of hospital staff with roles and departments         |
| patients.csv       | Patient details, admissions, service use, and satisfaction     |
| service_weekly.csv | Weekly service records including bed availability and morale   |
| staff_schedule.csv | Weekly attendance and staff assignment schedule                |

### Learning Goals

With these datasets, you’ll gain hands-on experience in both fundamental and advanced SQL techniques including:

- Writing queries with `SELECT`, `JOIN`, `WHERE`, `GROUP BY`, and `CASE`
- Working with subqueries, CTEs, and window functions
- Performing data aggregation and business analysis
- Solving practical hospital management scenarios
- Sharpening skills for data analyst interviews and case studies

### Usage Instructions

1. Import CSV files into your chosen SQL database (e.g., MySQL, PostgreSQL, SQLite)
2. Create tables reflecting the dataset structure:
   - patients
   - services_weekly
   - staff
   - staff_schedule
3. Tackle daily SQL challenges to improve your analytical thinking
4. Document your insights and queries in the repository

### Challenge Structure

This dataset supports a 21-day SQL challenge format, presenting a new business scenario each day—from basic queries to advanced joins, aggregations, and KPI calculations.

### Acknowledgment

The dataset was created exclusively for educational purposes as part of the Indian Data Club’s 21 Days SQL Challenge. All data is synthetic and does not represent any actual hospital.
